03 / Описание

Зачем этапозиция

Рядовой вентиляционный блок с внутренней перемычкой, сечение 430×210×180 мм. Перемычка разделяет ствол на два самостоятельных канала — типовое решение для пары «кухня — санузел» в одном стволе.

На что смотреть. Разделение каналов и их привязку к помещениям определяет проект вентиляции.

Схема габаритов вентиляционного блока ВБ-8

Частые вопросы

Зачем нужна перемычка?

Она разделяет ствол на два независимых канала, чтобы вытяжка из разных помещений не смешивалась.

Сколько блоков на поддоне?

60 штук, десять рядов по шесть. Блок весит 15,95 кг, поддон — 957 кг.
